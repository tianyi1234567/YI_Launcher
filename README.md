## 📖 简体中文

### 简介

这是一个 Minecraft（我的世界）启动器项目，主要用于**安装整合包与模组**，并提供一系列便捷的模组管理功能，例如**一键更新模组**等。

本项目的目标是让整合包与模组的安装、更新和管理尽可能简单，减少手动操作与出错的可能。

### ✨ 功能特性

- **整合包安装** — 支持一键安装整合包，自动处理配置与依赖
- **模组管理** — 便捷地安装、移除与整理模组
- **模组更新** — 检测并更新已安装模组至新版本
- **版本管理** — 管理多个 Minecraft 游戏版本与对应的模组环境
- **简单易用** — 面向普通玩家的图形化操作流程

> 功能仍在持续开发与完善中，实际功能以最新版本为准。

### 🚀 使用说明

1. 从**官方发布渠道**获取启动器（请勿从未经授权的第三方渠道下载）
2. 运行启动器，选择或创建游戏实例
3. 通过启动器安装整合包或模组
4. 启动游戏

> 具体操作请参考项目文档或发布页说明。

## 📖 English

### Introduction

This is a Minecraft launcher project focused on **installing modpacks and mods**, along with a set of convenient mod management features such as **one-click mod updates**.

The goal of this project is to make installing, updating, and managing modpacks and mods as simple as possible, reducing manual work and the chance of mistakes.

### ✨ Features

- **Modpack Installation** — One-click modpack installation with automatic configuration and dependency handling
- **Mod Management** — Easily install, remove, and organize mods
- **Mod Updates** — Detect and update installed mods to newer versions
- **Version Management** — Manage multiple Minecraft versions and their mod environments
- **Easy to Use** — A graphical workflow designed for regular players

> Features are under active development; actual functionality is subject to the latest release.

### 🚀 Getting Started

1. Obtain the launcher from **official release channels only** (do not download from unauthorized third-party sources)
2. Launch the application and select or create a game instance
3. Install a modpack or mods through the launcher
4. Start the game

> Please refer to the project documentation or release notes for detailed instructions.
